# /pwa-offline — بلا إنترنت وعلى شاشة الهاتف

1. شغّل من جذر المستودع: `python3 tools/pwa.py apps/<slug>` لتطبيق، أو `python3 tools/pwa.py --all` لكل التطبيقات.
   تكتب في مجلد التطبيق `manifest.webmanifest` و`icon.svg` و`sw.js`، وتربطها في `index.html` (آمنة إذا تكررت).
2. ما يُحفظ على الجهاز: ملفات التطبيق كلها، و`assets/design.css`، و`assets/quran.js`، و`data/quran.json` (المصحف كاملًا)،
   والخطوط بعد أول تحميل لها. اسم الذاكرة فيه بصمة الملفات، فكل تعديل يصل الهواتف في الزيارة التالية.
3. **أعد تشغيلها** كلما أضفت ملفًا لتطبيق (صوت، صورة، JSON) أو عدّلت ملفًا مشتركًا في `assets/` أو `data/`، وإلا بقيت الهواتف
   على النسخة القديمة أو نقصها الملف الجديد بلا إنترنت.
4. تأكد بـ `node tools/app_check.mjs <slug>`: يجب أن يظهر «يعمل بلا إنترنت ✓».
5. لا تعدّل `sw.js` باليد؛ عدّل `tools/pwa.py` إن احتجت سلوكًا آخر (مثل حفظ ملفات صوت كبيرة عند الطلب فقط بدل حفظها كلها).
6. ملفات الصوت الكبيرة: الأداة الآن تحفظ كل ملفات التطبيق مسبقًا، فلا تضع تلاوات كثيرة داخل مجلد التطبيق (قد تتجاوز مساحة الهاتف
   وحد GitHub Pages). إن احتاج تطبيق صوتًا كثيرًا فعدّل `tools/pwa.py` ليحفظ الصوت عند تشغيله أول مرة فقط.
